# results/figures/

Report-ready PNG charts generated by `scripts/generate_report_figures.py`
from the committed `results/aggregate/*` outputs only. **Committed to Git.**

Only aggregate charts derived from `results/aggregate/*.json`/`*.csv` may be
committed here — never a raw image, a per-sample score, an embedding, or
anything that could identify a specific LFW/CPLFW subject. Regenerate with:

```bash
python -m pip install -e '.[dev,review,report]'   # adds matplotlib
python scripts/generate_report_figures.py \
    --results-root results/aggregate --output-root results/figures
```
